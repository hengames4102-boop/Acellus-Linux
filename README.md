# Acellus-Linux
Unofficial Linux compatibility wrapper for Acellus using PyQt6 and QtWebEngine. Supports native Linux execution without Wine, virtual machines, or Waydroid.

## Installation

### Arch / EndeavourOS

[Click here to download for Arch Linux](https://www.dropbox.com/scl/fi/jzf1cbqf43do7sfsy7d95/acellus-linux-1.0-1-x86_64.pkg.tar.zst?rlkey=s3gct9uokqwibiarnbcijc1af&st=b65zpgtn&dl=1)

Install:
sudo pacman -U acellus-linux-1.0-1-x86_64.pkg.tar.zst

### Debian / Ubuntu / Linux Mint

[Click here to download for Debian/Ubuntu](https://www.dropbox.com/scl/fi/vf1u8p54eywjbfmwbep2h/acellus-linux_1.0_amd64.deb?rlkey=h9eh988s6bu3pj3yjd8mv8afm&st=lgt53o31&dl=1)

Install:
sudo dpkg -i acellus-linux_1.0_amd64.deb
sudo apt install -f
